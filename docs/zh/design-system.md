# Clipal 落地页设计规范

## 设计方向：Signal Brutalism（信号粗野主义）

页面以近黑底色（`#0a0a0a`）、温润纸白区块（`#f1f0ea`）与单一高饱和信号绿（`#c8ff3d`）构成三段式视觉节奏，配合大尺度标题、可见十二列网格、章节编号与锐利分割线建立辨识度。中英文共享同一套 DOM 结构、组件、资源与 13 帧交互逻辑；中文文案按中文开发者的搜索与阅读习惯独立编写，在章节标题中自然融入 `18 种 AI 编程 CLI`、`API 密钥`、`OAuth`、`故障转移`、`本机控制台` 等核心锚点词。

## 字体与色彩系统

- 英文主标题与全站斜体章节／步骤编号统一使用自托管可变字体 `EB Garamond`（正体与斜体）；正文与界面使用 `Geist`，命令、路由标签与元数据使用 `Geist Mono`，开源字库许可统一保存在 `landing-page/fonts/`。
- 中文标题前置 `EB Garamond` 处理拉丁字母与数字（如 `AI`、`CLI`、`18`），并按操作系统（`data-os`）适配最佳中文渲染：
  - **macOS / iOS (`apple`)**：使用多字重 `Songti SC`（宋体-简 `600`），呈现细腻高对比的编辑部宋体质感；
  - **Windows (`windows`)**：优先使用 `Source Han Serif SC` / `Noto Serif CJK SC`，无思源宋体时回退至支持 ClearType 真粗体的 `Microsoft YaHei UI`（`700`），规避点阵 `SimSun`（中易宋体）在大字号下合成伪粗体产生的断笔与锯齿；
  - **Linux / Android (`linux`)**：优先匹配 `Noto Serif CJK SC` / `Source Han Serif SC`。
- 颜色语义：底色 `--ink`（`#0a0a0a`）、纸白 `--paper`（`#f1f0ea`）、信号绿 `--acid`（`#c8ff3d`）、绿底深墨 `--acid-ink`（`#1f2b03`）、次要文字 `--muted`（`#a8a8a0`）、辅助标签 `--faint`（`#8a8a82`，满足深色背景 WCAG AA 对比度）、429 限流橙 `--heat`（`#ff5a1f`）、冷却琥珀色 `#d8b077`。所有状态均附带明确文字，不单靠颜色区分。

## 首屏构图与路由演示

- `.hero-meta` 置于左侧 `.hero-copy` 顶部，保留 `h1.display` 完整大标题气势，同时在主标题、中部 Copy & Demo 与底部客户端跑马灯之间留出舒展的纵向呼吸空间。
- 顶栏常驻主行动色按钮指向站内 `#install`（`开始使用`），`GitHub ↗` 使用克制线框样式，滚动时自动高亮当前章节并在双语切换时保留 `#hash` 锚点。
- 右侧路由演示面板明确标注为示意数据：上方三个客户端按钮经本机 Clipal（`127.0.0.1:3333` / `/clipal/*`）连接 `Anthropic`、`OpenAI`、`Gemini` 原生协议，再通过分支连线接入**单行双列**的 `提供商 01`（前置 `API` 方块）与 `提供商 02`（前置 `OAuth` 方块，`<= 520px` 自动切换单列堆叠）。
- 提供 `01 正常路由`、`02 兜底切换`、`03 黏性复用` 三个可点击场景标签，完整演绎直接成功、429 后进入持续冷却并切换兼容 OAuth 提供商、后续匹配请求黏性复用，播完一轮再切换客户端；离屏、后台标签页与 `prefers-reduced-motion: reduce` 下自动暂停。

## 控制台、集成、安装与常见问题

1. **本地控制台**：四个标签严格对应真实 Web UI——`提供商`（含各提供商 Token 用量与费用开销）、`CLI 接管`、`系统状态`（初始化检查项、运行时长、熔断器与通道当前路由）及`设置`（管理界面默认仅允许本地回环连接），支持原生 `<dialog>` 放大与原图打开。
2. **18 项 CLI 集成**：全部采用各品牌官方矢量图标置于深色徽标框内；非链接卡片悬停采用深灰提亮而非主按钮荧光绿填充；`<= 640px` 转为 64px 高紧凑双列，`<= 360px` 收紧内边距避免长名称折行。
3. **安装区**：桌面端左三列（1–3 列）配置粘性运行规格摘要（Go 单文件、无 Node 运行时依赖、默认回环地址与 `~/.clipal` 目录），平衡大面积荧光绿背景眩光；手机端复制按钮点击时将 `⧉` 切换为 `✓`，保持固定宽度。
4. **常见问题**：兼顾高频采纳场景（OAuth 账号与 API Key 混用兜底、完整配置回滚与卸载步骤）与产品真实边界说明（上游请求转发、凭证存储方式、原生协议路由及费用来源）。

## SEO 与 AI 发现性（GEO）

- 根目录包含 `robots.txt`、声明中英双向 `hreflang` 的 `sitemap.xml`，以及面向编程 Agent 与 AI 搜索引擎的 `llms.txt`。
- 中英文各自配备对称排版的 1200×630 分享图（`clipal-og-en.png`、`clipal-og-zh.png`）、独立 `@id` 的 `SoftwareApplication`（关联 GitHub 与 npm）及完整同步的 7 项 `FAQPage` JSON-LD；Cloudflare Pages `_headers` 覆盖 `/`、`/zh/`、`/llms.txt` 缓存策略与基础安全响应头。
