    Auto failover

    Automatic key and provider failover.

    In auto mode, Clipal tries the next available key on the same provider, then moves to another provider. Prefer a fixed route? Pin a provider in manual mode.

    Illustrative sequence
    Provider A
    key_01Selected
    key_02Standby
    Provider B
    key_01Standby

    01 / Start with the selected provider and key.

    02 / If needed, try the next available key on that provider.

    03 / Then try another compatible provider.

    Manual mode stays pinned; it does not switch keys or providers automatically.

    Install the platform-native binary via npm.

    npm install -g clipal

    curl -fsSL https://clipal.paiart.com/install.sh | sh

    05FAQ

    Local gateway, clear boundaries.

    Can I combine OAuth accounts (Claude, Codex, Antigravity) with pay-as-you-go API keys? +

    Yes. Add API-key providers and supported OAuth accounts to the same channel group. In auto mode, Clipal tries available keys on the current provider first, falls back across compatible API-key or OAuth providers when rate-limited, and reuses working routes for matching follow-up requests. You can also pin a single provider in manual mode.

    Does “local” mean my AI requests stay on my machine? +

    No. Clipal runs the gateway and management console locally, but sends API requests and necessary authentication information to the upstream providers you choose. It is not offline inference. By default, the management UI only accepts loopback connections; remote UI and proxy listening boundaries can be configured separately.

    Where does Clipal keep configuration and credentials? +

    API-key providers are stored in YAML under ~/.clipal. OAuth credentials live separately in ~/.clipal/oauth/. Protect those files with appropriate permissions on your machine; Clipal does not promise that all stored credentials are encrypted.

    What does rolling back CLI takeover restore? +

    Rollback restores the managed files to the original backup from the start of the current takeover cycle. Reapplying keeps that same backup. Project, session, and environment settings may still override the tool’s connection settings; open a new terminal after shell integration changes.

    Does Clipal translate between model protocols? +

    Clipal preserves the native Anthropic, OpenAI, and Gemini request families and routes by request path through /clipal/*. Use an upstream compatible with the protocol your tool sends; this is not arbitrary protocol conversion.

    How should I read the cost figures? +

    Clipal prefers upstream-reported cost. If that is unavailable, it uses the embedded pricing catalog for exact model matches. Unknown pricing is left missing, and catalog updates do not recalculate historical costs. Catalog-based figures are estimates, not a billing guarantee.

    How do I roll back CLI changes or uninstall Clipal cleanly? +

    Use Rollback in the CLI Takeover tab to restore managed files to their pre-takeover backup. If you installed the background service, run clipal service uninstall, then remove the binary (for example npm uninstall -g clipal) and delete ~/.clipal when you no longer need saved settings or usage history.
