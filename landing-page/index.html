ZERO-TRUST SECURITY ARCHITECTURE

Security Guarantees & FAQ

Transparent architectural documentation for discerning engineers.

Are my API keys and OAuth tokens sent to any cloud server?

Never. Clipal is 100% a local standalone executable. All keys, OAuth credentials, and session configs are encrypted on your local machine in config.json. Zero external telemetry. Open source on GitHub for independent auditing.

How does Clipal guarantee non-destructive configuration takeover?

Unlike scripts that overwrite entire config files, Clipal parses and merges AST syntax trees for JSON, YAML, and TOML. It injects only the required Base URL and preserves all your existing plugins, options, and variables. An immutable baseline snapshot is captured before applying, enabling 1-click byte-exact rollback at any time.

How does Clipal resolve handshake timeouts and DNS pollution?

Clipal features native proxy chain inheritance and tiered DoH resolution. In standard proxy environments, domain names are preserved and passed to the proxy. In direct environments, Cloudflare and Google DNS-over-HTTPS (DoH) are prioritized, cleanly eliminating handshake resets.

What is the unified /clipal route?

Starting with v0.25+, Clipal automatically detects incoming wire protocols. You simply set client endpoints to http://127.0.0.1:3333/clipal, and the gateway intelligently multiplexes Anthropic, OpenAI, and Gemini protocols.

Does using Clipal in Codex wipe my conversation history?

No, it improves stability. Clipal establishes a standardized model_provider = 'clipal' configuration. Rather than flipping provider names (which resets conversation sessions), Clipal maintains a unified identifier and shifts keys or endpoints internally.

How does npm 12+ handle install scripts?

Starting with v0.31, Clipal packages distribute binaries through platform optional dependencies rather than postinstall scripts. You can run npm install -g clipal directly without needing --allow-scripts.
