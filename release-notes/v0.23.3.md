## v0.23.3

### English

#### Improved

- Updated OAuth gateway transport identities to match Codex CLI `0.145.0`, Claude Code `2.1.220`, and Antigravity 2.0 `2.4.2`.
- Codex OAuth proxy and refresh requests now use the current Codex CLI version and user-agent prefix.
- Claude OAuth request, usage, billing-fingerprint, and live-smoke identities now use Claude Code `2.1.220`.
- Antigravity OAuth now falls back to the current Antigravity 2.0 version when a local application version is unavailable; macOS installations continue to use the installed app version when present.

#### Release Notes

- No YAML migration is required.
- Existing OAuth credentials and client takeover settings continue to work.

### 中文

#### 改进

- OAuth 网关传输身份已同步到 Codex CLI `0.145.0`、Claude Code `2.1.220` 和 Antigravity 2.0 `2.4.2`。
- Codex OAuth proxy 和 refresh 请求现在使用当前 Codex CLI 版本及 user-agent 前缀。
- Claude OAuth 请求、用量、billing fingerprint 和 live smoke 身份已更新为 Claude Code `2.1.220`。
- 当本地应用版本不可用时，Antigravity OAuth 会回退到当前 Antigravity 2.0 版本；macOS 上仍优先使用已安装应用的版本。

#### 发布说明

- 无需迁移 YAML 配置。
- 现有 OAuth 凭据和客户端接管配置可继续使用。
