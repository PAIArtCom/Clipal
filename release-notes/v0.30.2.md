## v0.30.2

### English

#### Service Installation

- `service install`, `service start`, and `service restart` validate configuration before changing the background service.
- These commands wait for the service health endpoint before reporting success, so a manager definition alone is not treated as a working installation.
- Service documentation now describes the same success criteria across macOS, Linux, and Windows.

#### Verification

- `go test ./...` passes.
- GolangCI-Lint passes with 0 issues.
- Security scan and smoke test pass.

### 中文

#### 服务安装

- `service install`、`service start` 和 `service restart` 会在修改后台服务前先校验配置。
- 这些命令会等待服务健康检查接口可用后才报告成功，不会把仅写入服务管理器配置当作安装成功。
- 服务文档现在为 macOS、Linux 和 Windows 说明统一的成功标准。

#### 验证

- `go test ./...` 通过。
- GolangCI-Lint 通过，0 issues。
- Security Scan 和 Smoke Test 通过。
