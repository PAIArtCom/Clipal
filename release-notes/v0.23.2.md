## v0.23.2

### English

#### Fixed

- Streaming Responses, Images, Chat Completions, and Claude requests now stop at complete protocol terminal events instead of waiting indefinitely for upstream EOF or trailing heartbeats.
- Large Base64 image events no longer lose their completion state, and SSE telemetry uses bounded memory without retaining or decoding full image payloads.
- Codex OAuth non-streaming compatibility responses now finish as soon as the upstream Responses terminal event is complete.
- SSE forwarding now preserves terminal event boundaries across LF, CRLF, and CR line endings, removes invalid upstream content lengths, and requests identity encoding for inspectable streams.
- Semantic failed or incomplete events no longer mutate circuit-breaker health as transport successes or failures.

---

### 中文

#### 修复

- Responses、Images、Chat Completions 和 Claude 流式请求会在完整协议终止事件后结束，不再无限等待上游 EOF 或后续心跳。
- 大型 Base64 图片事件不再丢失完成状态，SSE 遥测使用有界内存，不会保留或解析完整图片载荷。
- Codex OAuth 非流式兼容响应会在上游 Responses 终止事件完整后立即完成。
- SSE 转发现在可在 LF、CRLF、CR 换行下完整保留终止事件边界，同时移除无效的上游内容长度，并为可检查流请求 identity 编码。
- 语义失败或不完整事件不再被错误计为熔断器的传输成功或失败。
