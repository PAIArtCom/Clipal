## v0.30.1

### English

#### Windows

- Windows service installation adds the executable directory to the user's `PATH`.
- Task Scheduler runs the configured executable directly instead of maintaining a second copy under `%LOCALAPPDATA%`.
- `service install`, `service start`, and `service restart` verify that the task remains running before reporting success.
- Localized `schtasks` output, including Chinese Windows output, is recognized by service status parsing.

- Windows amd64 and arm64 release builds pass.
