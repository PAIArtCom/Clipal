## v0.32.0

### English

- Use **Test** in the provider details to fetch models, choose one, and send a separate generation request. The dialog shows which step failed or confirms successful generation. A successful test restores the tested provider and key if no newer failure occurred. Existing sticky sessions keep their routing.
- OpenAI API-key tests default to Responses and also support Chat Completions. **Retest** refreshes the model list and waits for your selection before sending another request.
- Updated the bundled OAuth client versions to Codex CLI `0.171.0`, Claude Code `2.1.329`, and Antigravity `2.33.0` (fallback).
- Reduced the executable size by compressing the embedded model catalog and excluding web tests. Release builds also strip local source paths.

### 中文

- 在 Provider 详情中点击「测试」，即可获取模型列表、选择模型并发送独立的推理请求。窗口会显示失败的步骤和原因，或确认推理成功。如果期间没有发生新的故障，测试成功会恢复该 Provider 和本次验证的 Key。现有会话继续沿用黏性路由。
- OpenAI API Key 测试默认使用 Responses，也支持 Chat Completions。点击「重测」会刷新模型列表，确认选择后才发送下一次请求。
- 内置 OAuth 客户端版本更新至 Codex CLI `0.171.0`、Claude Code `2.1.329` 和 Antigravity `2.33.0`（回退版本）。
- 通过压缩内嵌模型目录并排除前端测试文件，减小了可执行文件体积。发布构建也会移除本机源码路径。
