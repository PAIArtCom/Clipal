## v0.28.0

### English

#### Highlights

- Added takeover for Pi, Qwen Code, Kimi Code CLI, GitHub Copilot CLI, Kilo CLI, CodeBuddy Code, Crush, iFlow CLI, TRAE Agent, Grok Build and DeepSeek Harness, bringing the supported total to eighteen clients.
- All integrations share configuration previews, original-baseline backups, repeated apply, rollback and recovery. Client-specific options are exposed consistently through the API and Web UI.
- Verified all eleven additions with installed official clients, real gateway requests and two complete takeover/rollback cycles in private configuration directories.

#### Configuration and Compatibility

- Preserve unrelated configuration, existing authentication and model metadata. Model IDs come from existing configuration or an explicit gateway selection; takeover does not invent default model names or context lengths.
- Kilo uses the shared OpenCode-compatible planner with its own configuration-file precedence. Known later routing overrides block takeover; other planning inputs remain read-only and are checked again before writing.
- Kimi requires existing context metadata or an explicitly selected positive context budget. TRAE requires the actual YAML configuration file used at launch.
- Copilot uses the documented shell BYOK contract and refuses a populated provider registry that would override it. Open a fresh terminal after apply and rollback.
- Crush supports its still-valid legacy user JSON configuration. Executable shell configuration and conflicting machine-state routing block automatic takeover.
- Qoder, Amp, Cursor CLI and Kiro CLI remain outside automatic takeover pending a sufficiently verified local configuration and inference contract. See the [client catalog](https://github.com/PAIArtCom/Clipal/blob/v0.28.0/docs/cli-takeover-candidates.md) for exact boundaries and executed versions.

#### Verification and Release Reliability

- Eleven official clients returned verified assistant replies and fresh gateway HTTP 200 results. Tests checked original bytes and permissions after rollback and preserved intervening edits in a second cycle. Watched standard user configuration paths remained unchanged.
- The live runner rejects prompt echoes and unsuccessful final states, terminates timed-out client process groups, and reports cleanup failures as failures. TRAE verification checks successful completion with its `task_done` tool. Eight dependency-free harness regressions run in CI.
- DeepSeek verification used the official npm `latest` release candidate, 0.2.0-rc.2; no stable release is published. TRAE used the current official source commit and lockfile-compatible dependencies. These minimal requests do not establish every model, tool or enterprise configuration.
- Client tests clear inherited directory, inline and routing overrides, including `XDG_CONFIG_HOME`, with hostile-environment regression checks.
- GitHub Release and npm publication depend on CI and security checks of the exact publication commit. Failed, cancelled or skipped prerequisites prevent publication.

### 中文

#### 亮点

- 新增 Pi、Qwen Code、Kimi Code CLI、GitHub Copilot CLI、Kilo CLI、CodeBuddy Code、Crush、iFlow CLI、TRAE Agent、Grok Build 和 DeepSeek Harness 接管，支持总数增至十八家。
- 所有接入共用配置预览、原始基线备份、重复 apply、rollback 和失败恢复；API 与 Web UI 根据客户端能力统一展示可用选项。
- 安装官方客户端，在独立配置目录中完成新增十一家的真实网关请求及两轮接管／回滚验证。

#### 配置与兼容性

- 保留无关配置、已有认证与模型元数据。模型 ID 来自现有配置或明确选择的网关模型，不拼造默认模型名或上下文长度。
- Kilo 复用 OpenCode 兼容规划器，并遵循自身的多文件优先级；已知后续路由覆盖会阻止接管，其他规划来源保持只读，写入前再次检查是否变化。
- Kimi 需要已有上下文元数据或明确填写正数上下文预算；TRAE 必须选择实际启动时使用的 YAML 配置。
- Copilot 使用官方 shell BYOK 契约；已有 provider registry 会覆盖该配置时，拒绝自动接管。应用及回滚后需打开新终端。
- Crush 支持仍有效的旧式用户 JSON 配置；存在可执行 shell 配置或机器状态路由冲突时，阻止自动接管。
- Qoder、Amp、Cursor CLI、Kiro CLI 暂不提供自动接管，待进一步确认本地配置及推理契约。具体边界与实际验证版本见[客户端清单](https://github.com/PAIArtCom/Clipal/blob/v0.28.0/docs/cli-takeover-candidates.md)。

#### 验证与发布可靠性

- 十一家官方客户端均返回已核验的助手回复及新的网关 HTTP 200 记录；回滚恢复原始内容和权限，第二轮接管保留周期之间的用户修改，监测的标准用户配置路径未变化。
- 真实客户端脚本拒绝把提示回显或未完成状态计作成功，超时后终止客户端进程组，清理失败时报告失败。TRAE 通过 `task_done` 正常结束任务；八项无需上游账号的脚本回归纳入 CI。
- DeepSeek 使用官方 npm `latest` 指向的 0.2.0-rc.2，目前没有稳定正式版；TRAE 使用最新官方源码及锁文件兼容依赖。最小请求验证不代表覆盖全部模型、工具或企业配置。
- 客户端测试清除继承的目录、内联配置和路由覆盖，包括 `XDG_CONFIG_HOME`，并补齐污染环境回归检查。
- GitHub Release 和两个 npm 包的发布依赖准确目标提交的 CI 与安全检查；前置检查失败、取消或跳过时，不执行发布。
