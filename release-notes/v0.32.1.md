## v0.32.1

### English

- **OAuth Client Compatibility**: Updated bundled OAuth client identities to Codex CLI `0.172.0`, Claude Code `2.1.332` (Node `v26.13.1`), and Antigravity `2.35.2`.
- **Native Dialogs & Top-Layer Overlays**: Migrated Web UI modals to native `<dialog>` and `popover="manual"` top-layer overlays so notifications and loading spinners stay above open dialogs, nested confirmations keep parent modal state intact, and page scroll behind modals is contained.
- **Provider Test & Form Polish**:
  - Refined the provider test dialog's visual hierarchy by grouping the step progress indicator with the active stage content and unifying the Model and Endpoint controls onto consistent native `<select>` dropdowns.
  - Collapsed provider **Overrides** into a compact disclosure by default (showing the active model override badge when collapsed) and removed reasoning/thinking effort controls from the Web UI (YAML configuration remains supported).
- **Landing Page**: Improved mobile navigation focus management and background `inert` handling, switched display headings to fluid `rem`/`vw` scaling, and added responsive `srcset` mobile screenshot assets.

### 中文

- **OAuth 客户端兼容性**：更新内置 OAuth 客户端指纹至 Codex CLI `0.172.0`、Claude Code `2.1.332`（Node `v26.13.1`）和 Antigravity `2.35.2`。
- **原生弹窗与顶层通知修复**：将 Web UI 弹窗迁移至原生 `<dialog>` 与 `popover="manual"` 顶层机制，确保通知和加载遮罩在弹窗之上正常显示、嵌套确认弹窗不会关闭父弹窗，并阻止背景页面滚动穿透。
- **Provider 测试与表单优化**：
  - 优化 Provider 测试弹窗的视觉层级，将步骤条与操作内容区归为一体，并统一模型与接口下拉框为原生 `<select>` 交互。
  - 将 Add / Edit Provider 弹窗中的「覆盖」区域改为默认收起（收起时以胶囊展示已配置的模型覆盖），并从界面中移除推理/思考强度覆盖选项（仍兼容已有 YAML 配置）。
- **落地页优化**：改进移动端导航菜单的焦点管理与背景 `inert` 范围，优化响应式流式字号排版，并为控制台截图补充移动端 `srcset` 资源。
