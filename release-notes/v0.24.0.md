## v0.24.0

### English

#### Highlights

- Added reproducible offline usage-cost calculation from an embedded, integrity-checked `PAIArtCom/model-specs` catalog.
- Added cost-source and pricing-catalog attribution to stored usage, provider usage responses, and system status.
- Strengthened data import with short-lived immutable review plans, idempotent Apply retries, serialized execution, and bounded concurrency.

#### What Changed

- Usage costs prefer values reported by the upstream response and otherwise use exact model prices from the embedded catalog, including cache, service-tier, long-context, reasoning, audio, and search rates.
- Claude Opus 4.6 fast mode applies Anthropic's 6x multiplier to catalog token rates; per-query search charges are unchanged.
- `usage.json` is written using storage version 4. Existing unattributed costs are retained as `legacy_unknown`, and catalog-derived costs retain every represented catalog version.
- Native imports always add historical usage to the latest counters, including when configuration and credentials use `replace` mode.
- Malformed auxiliary usage and cost-attribution fields are ignored or normalized with preview warnings; they do not block an otherwise valid import. Configuration, credential, persistence, and runtime-reload failures remain transactional errors.
- Reviewed import plans remain available in memory for 15 minutes, with at most 32 retained plans. Repeating a successful Apply for a retained plan returns the prior result without adding usage again.

#### Maintenance

- Updated bundled OAuth transport identities to Codex CLI `0.153.4`, Claude Code `2.1.263`, and Antigravity 2.0 `2.12.2`.
- Updated Go dependencies, GitHub Actions, golangci-lint, and govulncheck. The `golang.org/x/net` update also resolves the HTTP/2 client initialization panic observed with Go 1.27.

### 中文

#### 亮点

- 新增基于离线内置 `PAIArtCom/model-specs` 目录的可复现用量费用计算，并在加载时校验目录完整性。
- 持久化用量、Provider 用量响应和系统状态新增费用来源与定价目录版本归因。
- 数据导入新增短时不可变审查计划、幂等执行重试、串行事务和并发数量限制。

#### 变更内容

- 用量费用优先采用上游响应直接报告的值，否则按内置目录中的精确模型价格计算，支持缓存、服务等级、长上下文、推理、音频和搜索费率。
- Claude Opus 4.6 fast 模式会对目录 token 费率应用 Anthropic 的 6 倍倍率，按次搜索费用不变。
- `usage.json` 现在使用存储版本 4。既有且无法归因的费用保留为 `legacy_unknown`，目录计算费用会保留聚合中包含的全部目录版本。
- 原生数据导入始终把历史用量累加到最新计数，即使配置和凭据采用 `replace` 模式也是如此。
- 异常的辅助用量或费用归因字段会被忽略或规范化，并在预览中显示 warning，不会阻断其他有效数据的导入；配置、凭据、持久化和运行时重载失败仍属于需要整体回滚的事务错误。
- 已审查导入计划在内存中保留 15 分钟，最多保留 32 个；在保留期内重复执行已成功的计划会返回先前结果，不会再次累加用量。

#### 维护

- 内置 OAuth 传输身份已更新为 Codex CLI `0.153.4`、Claude Code `2.1.263` 和 Antigravity 2.0 `2.12.2`。
- 升级 Go 依赖、GitHub Actions、golangci-lint 和 govulncheck；其中 `golang.org/x/net` 升级同时修复了 Go 1.27 下观察到的 HTTP/2 客户端初始化空指针。
