## v0.31.0

### English

#### npm

- `clipal` and `@paiart/clipal` now ship the binary through platform-specific optional dependencies and no longer run a `postinstall` download. npm 12 and newer install them without `--allow-scripts`.
- If optional dependencies are skipped, the wrapper downloads the matching GitHub release asset and verifies `checksums.txt`.
- Reinstall with `npm install -g clipal --include=optional` to restore a skipped platform package.

#### Standalone installers

- macOS and Linux: `curl -fsSL https://clipal.paiart.com/install.sh | sh`
- Windows: `powershell -ExecutionPolicy ByPass -c "irm https://clipal.paiart.com/install.ps1 | iex"`
- Both scripts detect the platform, download the matching release asset, verify it against `checksums.txt`, and install to a user-writable directory.
- Set `CLIPAL_VERSION` to pin a release, `CLIPAL_INSTALL_DIR` to choose the install directory, and `CLIPAL_DOWNLOAD_BASE_URL` to configure a mirror.
- Support `--dry-run` on Unix and `CLIPAL_DRY_RUN=1` on Windows to preview the install plan without making changes.
- The installers are attached to every GitHub release and served from `clipal.paiart.com`.

#### Security & Dependencies

- Updated Go toolchain to `1.27.4` to address standard library HTTP/1 race vulnerabilities.
- Updated `github.com/andybalholm/brotli` to `v1.2.7` and `github.com/klauspost/compress` to `v1.20.2`, resolving all reported vulnerabilities.

#### Verification

- `go test ./...` passes.
- `./scripts/test_npm_packaging.sh` passes.
- `./scripts/test_installers.sh` passes.
- Verified the standalone installer against the latest published release on macOS.

### 中文

#### npm

- `clipal` 和 `@paiart/clipal` 改为通过平台可选依赖分发二进制，不再执行 `postinstall` 下载。npm 12 及以上版本无需 `--allow-scripts` 即可安装。
- 如果安装时跳过了可选依赖，wrapper 会从对应的 GitHub Release 下载二进制，并用 `checksums.txt` 校验。
- 可以用 `npm install -g clipal --include=optional` 重新安装被跳过的平台包。

#### 独立安装脚本

- macOS / Linux：`curl -fsSL https://clipal.paiart.com/install.sh | sh`
- Windows：`powershell -ExecutionPolicy ByPass -c "irm https://clipal.paiart.com/install.ps1 | iex"`
- 两个脚本都会自动识别平台，下载对应的 release 文件，用 `checksums.txt` 校验后安装到用户可写目录。
- 可以通过 `CLIPAL_VERSION` 固定版本，用 `CLIPAL_INSTALL_DIR` 指定安装目录，通过 `CLIPAL_DOWNLOAD_BASE_URL` 配置镜像源。
- Unix 脚本支持 `--dry-run`，Windows 脚本支持 `CLIPAL_DRY_RUN=1` 在不变更系统的情况下预览安装计划。
- 安装脚本会随每个 GitHub Release 发布，并通过 `clipal.paiart.com` 提供固定地址。

#### 安全与依赖更新

- 升级 Go 工具链到 `1.27.4`，修复标准库 HTTP/1 race 漏洞。
- 升级 `github.com/andybalholm/brotli` 到 `v1.2.7`，升级 `github.com/klauspost/compress` 到 `v1.20.2`，修复所有已知的依赖 CVE。

#### 验证

- `go test ./...` 通过。
- `./scripts/test_npm_packaging.sh` 通过。
- `./scripts/test_installers.sh` 通过。
- 已在 macOS 上使用最新正式版本验证独立安装脚本。
