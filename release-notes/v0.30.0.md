## v0.30.0

### English

#### Highlights

- Codex OAuth providers now serve the Codex model catalog, so Codex CLI can discover the models available to its authenticated account through Clipal.
- Clipal supports both Codex-native `GET /models?client_version=...` and OpenAI-compatible `GET /v1/models` catalog requests on the proxied route.

#### Compatibility

- Catalog requests forward only the supported `client_version` parameter to the Codex upstream and return the protocol-appropriate response shape. This prevents model discovery from being treated as an unavailable OpenAI provider request.

#### Verification

- Go tests, static analysis, cross-platform builds, and live catalog requests against a local Codex OAuth configuration pass.

---

### 中文

#### 亮点

- Codex OAuth Provider 现可提供 Codex 模型目录，Codex CLI 能够通过 Clipal 发现当前已认证账号可用的模型。
- Clipal 同时支持代理路由上的 Codex 原生 `GET /models?client_version=...` 与 OpenAI 兼容的 `GET /v1/models` 模型目录请求。

#### 兼容性

- 目录请求只会将受支持的 `client_version` 参数转发到 Codex 上游，并返回相应协议要求的响应格式；模型发现不会再被当作不可用的 OpenAI Provider 请求。

#### 验证

- 已通过 Go 测试、静态分析、跨平台构建，以及使用本机 Codex OAuth 配置进行的真实模型目录请求验证。
