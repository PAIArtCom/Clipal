## v0.24.2

### English

#### Highlights

- Self-update now shows live download progress in interactive terminals and stage-oriented logs in non-interactive environments.
- Updated bundled OAuth transport identities to match the latest upstream releases.

#### What Changed

- `clipal update` reports release check, checksum download, binary download, SHA256 verification, and installation stages. An interactive terminal refreshes download percentage, transferred size, speed, and ETA in place; CI and redirected output receive stable line-oriented stage logs instead. Progress is written to stderr.
- Added `--quiet` flag to suppress self-update progress output.
- On Windows, the updater helper reports that the update is scheduled and confirms replacement after the current process exits.

#### Maintenance

- Updated bundled OAuth transport identities to Codex CLI `0.155.1`, Claude Code `2.1.278` (Anthropic SDK `0.208.0`), and Antigravity 2.0 `2.13.0`.

### 中文

#### 亮点

- 自更新现在在交互终端中显示实时下载进度，非交互环境下输出阶段日志。
- 内置 OAuth 传输身份已更新至上游最新版本。

#### 变更内容

- `clipal update` 报告版本检查、校验和下载、二进制下载、SHA256 验证和安装各阶段进度。交互终端中原地刷新下载百分比、已传输大小、速度和 ETA；CI 和重定向输出则收到稳定的逐行阶段日志。进度信息输出到 stderr。
- 新增 `--quiet` 标志以关闭自更新进度输出。
- Windows 上，更新辅助程序先报告更新已调度，待当前进程退出后完成替换并确认。

#### 维护

- 内置 OAuth 传输身份已更新为 Codex CLI `0.155.1`、Claude Code `2.1.278`（Anthropic SDK `0.208.0`）和 Antigravity 2.0 `2.13.0`。
