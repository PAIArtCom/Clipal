## v0.23.4

### English

#### Improved

- Updated OAuth gateway transport identities to match Codex CLI `0.149.0`, Claude Code `2.1.240`, and Antigravity 2.0 `2.9.1`.
- Updated Codex OAuth proxy and refresh requests, Claude OAuth usage, billing-fingerprint and live-smoke requests, and both Antigravity OAuth fallback paths.
- Added regression tests to keep the two Antigravity OAuth fallback identities aligned.

#### Security

- Updated the project Go toolchain to `1.26.7`, which includes the standard-library fixes required by the security scan.

#### Release Notes

- No YAML migration is required.
- Existing OAuth credentials and client takeover settings continue to work.

### 中文

#### 改进

- OAuth 网关传输身份已同步到 Codex CLI `0.149.0`、Claude Code `2.1.240` 和 Antigravity 2.0 `2.9.1`。

- 项目 Go 工具链已更新到 `1.26.7`，包含安全扫描所需的标准库漏洞修复。

#### 发布说明

- 无需迁移 YAML 配置。
- 现有 OAuth 凭据和客户端接管配置可继续使用。
