## v0.24.3

### English

#### Highlights

- Updated the embedded pricing catalog with Claude Opus 5.5, GPT-6 Sol/Luna, and Gemini 3.7/3.8 Flash.
- Usage costs now include Anthropic fast-mode and US data-residency premiums, and batch cache rates.
- Updated bundled OAuth transport identities to match the latest upstream releases.

#### What Changed

- Embedded `PAIArtCom/model-specs` catalog `837282acddc5` (3931 models). Client model lists now include `claude-opus-5-5` for Claude Code, `gpt-6-sol` and `gpt-6-luna` for Codex (`gpt-5.2` removed), and `gemini-3.7-flash` and `gemini-3.8-flash` for Antigravity (`gemini-3.5-flash` removed).
- Fast mode (`usage.speed=fast`) now uses each model's catalog multiplier: 2x for Claude Opus 4.8, Opus 5, and Opus 5.5. Claude Opus 4.6 keeps its 6x rate. Previously only Opus 4.6 fast mode was priced.
- When Anthropic reports `usage.inference_geo=us`, token costs include the model's US regional premium (1.1x for Claude 4.6 and later). Fast-mode and regional premiums stack; per-query search charges are not multiplied.
- Batch requests use batch-specific cache read and cache write prices, and batch requests above 272K input tokens are priced from combined batch long-context rates instead of being left unpriced.
- Previously recorded usage costs are not repriced.

#### Maintenance

- Updated bundled OAuth transport identities to Codex CLI `0.156.0` and Claude Code `2.1.280` (Anthropic SDK `0.208.0`).

### 中文

#### 亮点

- 内置价格目录新增 Claude Opus 5.5、GPT-6 Sol/Luna 以及 Gemini 3.7/3.8 Flash。
- 用量费用现在计入 Anthropic fast 模式和美国数据驻留溢价，以及 batch 缓存价格。
- 内置 OAuth 传输身份已更新至上游最新版本。

#### 变更内容

- 内置 `PAIArtCom/model-specs` 目录更新为 `837282acddc5`（3931 个模型）。客户端模型列表：Claude Code 新增 `claude-opus-5-5`；Codex 新增 `gpt-6-sol`、`gpt-6-luna`，移除 `gpt-5.2`；Antigravity 新增 `gemini-3.7-flash`、`gemini-3.8-flash`，移除 `gemini-3.5-flash`。
- fast 模式（`usage.speed=fast`）改用各模型目录中的倍率：Claude Opus 4.8、Opus 5、Opus 5.5 为 2 倍，Claude Opus 4.6 保持 6 倍。此前仅对 Opus 4.6 的 fast 模式计价。
- 当 Anthropic 报告 `usage.inference_geo=us` 时，token 费用计入该模型的美国地域溢价（Claude 4.6 及之后为 1.1 倍）。fast 模式与地域溢价叠加；按次搜索费用不乘以溢价。
- batch 请求使用 batch 专用的缓存读取与写入价格；输入超过 272K token 的 batch 请求改用 batch 长上下文组合价格计费，不再保持未计价。
- 已记录的历史用量费用不会重新计价。

#### 维护

- 内置 OAuth 传输身份已更新为 Codex CLI `0.156.0` 和 Claude Code `2.1.280`（Anthropic SDK `0.208.0`）。
